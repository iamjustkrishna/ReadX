# Social Automation Rules

## Approval

Never publish directly to a social account without explicit final approval from the user for the exact post or batch.

## Allowed By Default

- Draft posts.
- Create content calendars.
- Create visual briefs.
- Prepare platform-specific captions.
- Prepare hashtags.
- Prepare manual posting instructions.
- Prepare API integration plans.

## Requires Explicit Setup

- Connecting X, Instagram, LinkedIn, Canva, or other accounts.
- Storing tokens.
- Creating developer apps.
- Scheduling or publishing posts.
- Reading private analytics.

## Platform Notes

- X posting requires developer access and API credentials.
- Instagram publishing requires an Instagram Professional account, a connected Facebook Page, a Meta app, and publishing permissions.
- LinkedIn publishing requires OAuth and LinkedIn app permissions.
- Canva automation requires Canva Connect API access or a connected MCP/plugin with Canva actions.

## Safety

- Store credentials outside tracked files.
- Use least-privilege scopes.
- Keep an approval queue.
- Log what was posted, when, where, and by whom.
