# Operating Rules

## Before Work

- Read `state/project.md` and `state/current.md`.
- Read the relevant agent, workflow, and rule files.
- Inspect the actual repo before making claims about code.
- Do not overwrite unrelated user changes.

## During Work

- Prefer small, focused changes.
- Follow existing Android/Kotlin/Compose patterns.
- Keep app code useful without AI.
- Treat API keys, tokens, credentials, and account access as sensitive.
- Do not add large new dependencies unless they clearly reduce risk or complexity.

## After Work

- Run the smallest meaningful verification available.
- Update `state/current.md` for meaningful work.
- Update `state/decisions.md` for lasting decisions.
- Update `state/backlog.md` when priorities change.
- Mention anything not verified.
