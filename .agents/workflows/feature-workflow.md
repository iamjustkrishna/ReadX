# Feature Workflow

## Steps

1. Read `state/project.md` and `state/current.md`.
2. Inspect the relevant code.
3. Define the smallest useful feature slice.
4. Implement using existing project patterns.
5. Run targeted verification.
6. Update `state/current.md`.
7. Update `state/backlog.md` if follow-up work remains.

## Done When

- The feature works in the intended flow.
- Existing behavior is not knowingly broken.
- Verification results are recorded.
