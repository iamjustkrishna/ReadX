# Social Publishing Workflow

## Steps

1. Draft posts and asset briefs.
2. Put posts into an approval queue.
3. Get explicit user approval for exact content.
4. Publish manually or through connected API.
5. Log platform, content, date, link, and result.

## Direct Posting Requirements

- Connected account.
- Valid token.
- Correct API permissions.
- User approval.
- Post log update.

## Current Status

Direct publishing is not configured. Use draft/manual mode until a platform-specific MCP/API is connected.
