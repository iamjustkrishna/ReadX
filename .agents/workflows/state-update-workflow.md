# State Update Workflow

## Steps

1. Summarize what changed.
2. Update `state/current.md`.
3. Add durable decisions to `state/decisions.md`.
4. Add or remove backlog items.
5. Update launch status if user-facing readiness changed.

## Rules

- Use dates.
- Be specific.
- Remove stale state when it is no longer true.
- Do not treat guesses as facts.
