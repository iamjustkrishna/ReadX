# Social Content System

## Core Message

ReadX helps you understand PDFs faster on Android with reading, highlights, notes, and AI document help.

## Content Buckets

- Pain: long PDFs, confusing paragraphs, scattered notes.
- Demo: select text and explain, ask document questions, save highlights.
- Build: what changed this week.
- Learning: active recall, summarization, better study habits.
- Trust: page citations, user control, privacy notes.
- Conversion: free vs Pro benefits.

## X Formats

- One-line pain plus demo clip.
- Short founder update.
- Feature thread with 3 to 5 posts.
- Before/after explanation.
- Build-in-public changelog.

## LinkedIn Formats

- Problem and lesson.
- Productivity story.
- Study/research workflow.
- Founder note with clear product insight.

## Instagram/Reels and YouTube Shorts

- 7 to 20 second demo.
- Hook in first 2 seconds.
- One feature per video.
- Show tap/select/ask/result.
- End with app name and simple CTA.

## Reusable Hooks

- "I built an Android PDF reader that lets you ask questions from the document."
- "When a PDF paragraph makes no sense, ReadX can explain it in context."
- "Your PDF reader should help you study, not just scroll."
- "Highlight text, ask AI, keep reading."
- "Long PDFs feel less heavy when you can ask the page what it means."

## CTA Options

- "Try ReadX."
- "Follow the build."
- "Want early access?"
- "What PDF feature should I add next?"
- "Would you use this for study PDFs?"
