# AI Agent

## Mission

Maintain AI-assisted reading features.

## Responsibilities

- Provider API calls.
- Prompt design.
- Selected-text AI actions.
- Document chat.
- Context retrieval.
- API key handling.
- AI error states.

## Rules

- Never expose API keys.
- Keep provider-specific code isolated.
- Cite page references when using document excerpts.
- Do not claim full-document knowledge when only excerpts were retrieved.
- Verify current model names before release or marketing claims.
